# EasyVPN

EasyVPN - это проси-клиент для Windows, построенный на базе ядра [sing-box](https://github.com/SagerNet/sing-box). Программа предназначена для автоматического парсинга, проверки и маршрутизации всего трафика вашего ПК через рабочие VLESS-серверы. Если ваши руки прямые, используйте [ToInet](https://github.com/AlexeyRF/ToInet)

## Особенности
- **Автоматический парсинг подписок:** Скачивает списки VLESS-узлов по ссылкам (поддерживаются как прямые списки, так и Base64-кодированные подписки).
- **Умная балансировка (urltest):** Оставшиеся рабочие узлы скармливаются в ядро `sing-box`, которое измеряет задержку и переключает ваш трафик на самый быстрый сервер.
- **Проксирование всего устройства:** Используя виртуальный сетевой адаптер, весь трафик вашей операционной системы и любых программ автоматически заворачивается в прокси.
- **Свой локальный DNS:** Обход проблем с блокировками DoH и отсутствием поддержки UDP у части VLESS-серверов.

## Установка и настройка

1. Распакуйте файлы в любую удобную папку.
2. Убедитесь, что в папке с программой лежит ядро **`sing-box.exe`** (версии 1.13 или новее).
3. Создайте или отредактируйте файл **`subs.txt`** в этой же папке. Добавьте в него прямые ссылки на ваши VLESS-подписки (каждая ссылка с новой строки).
4. Запустите **`EasyVPN.exe`** (скомпилированную версию) или скрипт **`python main.py`**. 
   > **Важно!** Запуск должен производиться строго **от имени Администратора**. Это необходимо для того, чтобы sing-box смог создать виртуальный адаптер TUN и изменить таблицу маршрутизации Windows. Скомпилированный `EasyVPN.exe` уже настроен на автоматический запрос админских прав при старте.

## Как пользоваться

1. Запустите программу.
2. Нажмите огромную кнопку **"OFF"**.
3. Дождитесь, пока программа скачает подписки и проверит их (статус будет отображаться в окне).
4. Как только появится зеленая надпись **"ON"** и статус "Подключено", ваш трафик надежно проксируется.
5. Для отключения просто нажмите на кнопку еще раз, либо закройте программу.

## Сборка из исходников (Python)

Если вы хотите скомпилировать `.exe` файл самостоятельно из исходника `main.py`, вам понадобится Python 3.x и библиотека `PyQt6`.

Установка зависимостей:
```cmd
pip install PyQt6 pyinstaller
```

Компиляция с вшитым запросом прав Администратора (UAC):
```cmd
pyinstaller --noconsole --onefile --uac-admin --name "EasyVPN" main.py
```
Готовый `EasyVPN.exe` появится в папке `dist`.

## Возможные проблемы
- **Не запускается sing-box (Ошибка в интерфейсе):** Убедитесь, что `sing-box.exe` находится в одной папке с `main.py` или `EasyVPN.exe`.
- **VPN пишет "Подключено", но IP не меняется:** Убедитесь, что вы запустили программу от имени Администратора (без этого Wintun не сможет перехватить трафик).
- **Нет доступных серверов:** Проверьте доступность ссылок в файле `subs.txt` и убедитесь, что ваш провайдер не блокирует скачивание самих подписок.
